Four Keystones.

Folders, markdown files, scripts and protocols, each tailored to the agency's own roles, rounds and clients.

01 Folders. A project structure built around the agency's own stages and deliverables.

02 Markdowns. Client mandatories, legal lines, rights, licenses and decisions, each in one file that people and AI tools both read from.

03 Scripts. Older versions move to an archive folder, so the main folder only holds the current one. Each change reaches every template that uses it.

04 Protocols. Who gets which changes, which roles review which rounds, and what travels with the work between departments.
